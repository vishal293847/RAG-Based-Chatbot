
# RAG-Based AI Chatbot

An intelligent conversational AI application built using Retrieval-Augmented Generation (RAG) to provide accurate, context-aware responses based on uploaded or stored documents.

## Key Features
- Document ingestion and preprocessing
- Intelligent text chunking
- Text embeddings and semantic search
- Context-aware question answering
- LLM integration using Gemini and Ollama
- Elasticsearch-based document retrieval
- MongoDB integration for data management
- Efficient information retrieval using RAG architecture

## Technologies Used
Python, LangChain, Gemini API, Ollama, Elasticsearch, MongoDB, NLP, and Embeddings.

## Objective
To reduce manual document searching and enable users to retrieve relevant information through a natural-language conversational interface.
